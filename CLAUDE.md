# Repository notes for Claude

Before changing Hull or proposing new reconstruction features, read
[`KNOWLEDGE_FILE.md`](KNOWLEDGE_FILE.md). It maps the existing engines, input
requirements, active call paths, known failures and verification limits.

This repo holds two unrelated projects:

- **Midnight Watch** (repo root): a static web app. See docs/legacy/MIDNIGHT_WATCH.md.
- **Long Lines** (`long-lines/`): a Godot 4.4 game prototype. **Read `long-lines/CLAUDE.md` before working on it.**
