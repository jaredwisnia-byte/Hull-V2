# Deprecated and archived components

- `midnight-watch/`: unrelated web application, assets, collector and workflow.
  Repository search found no runtime references from Hull or Long Lines.
- Hull proportional part budgeting (`budget: share`) is a deprecated compatibility
  option kept in place: existing work orders may explicitly request it. Default
  builds now use fixed screen-error reduction. It is not safe to delete dynamic
  recipe/dispatcher modules merely because a static search finds no caller.

No reconstruction engine, historical fixture, sizing manual, game consumer, or
optional backend was removed. These remain active or require stronger evidence.
