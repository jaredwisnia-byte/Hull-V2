## Fixed (verified)
- Lever as a full-width shelf: separate parts take their width from the end-on view
  (`e47a82c`, branch, **not merged**). Typewriter outline error 2.0-5.5 mm -> 1.0-1.5 mm; other six
  objects byte-identical.
- CAD path memory: 13-20 GiB -> ~3 GiB (`7a99c43`, main).
- Stranded modules found and recorded (`docs/STRANDED_MODULES.md`, branch).

## Open defects (seen in the models)
1. **Textures doubled** where views disagree (typewriter: keys and space bar twice). Cause: views are
   aligned by their outline boxes; the top view is stretched 12 %. The draftsman registration fixes
   the alignment but is not used for texture projection.
2. **Knobs boxy**: the body's side wall reaches out to the knobs, so no outline or feature rule can
   round them; needs parts as solids (step 3-4).
3. **Keys missing / keyboard a smooth slope**: the voxel body cannot hold key-scale detail; needs the
   keyboard cut back and keys as solids (step 3-4); only 1 of 3 rows validates yet (depth alignment
   near the front).
4. **Type basket a plateau, not a hollow** (recess not built).
5. **Dryer barrel square, mixer bowl boxy** (end-view circle overruled / hidden).
6. **Controls a few mm off** (toaster dial): export grounding shift, height handoff (run 8 findings).
7. **CAD folds** on four objects.

## Uncommitted switches that change builds (must default off until they beat the current pipeline)
- `blades` (top-down cut): **on by default** in `vision_order.py`; mixed result (folds down, triangles
  doubled). -> default off.
- Key rows (`features.apply` kind `row`) and `part_solids` (`HULL_PART_SOLIDS`): on by default; no
  visible gain yet. -> default off.
- Knob rule (`end_shapes`): runs, cuts nothing on the seven. Harmless; keep, recorded.
- Stage reports in the build log (`CONSTRUCTION_STAGES`): keep.

## Plan, most critical first
1. **Make the branch safe and save it.** New construction switches default off; verify the seven
   image-only objects build byte-identical to the lever-fix build (typewriter) and the baseline
   (others); commit the draftsman stage as evidence with its tests. Ask Jared to merge.
2. **Texture alignment (defect 1).** Project each view through the draftsman registration (the same
   warp the sheet uses) instead of its stretched outline box. Geometry unchanged; textures checked on
   all seven; the doubled keys and space bar must collapse to one.
3. **Parts as CAD solids (step 3).** The draftsman's confirmed parts go into `cad_model` as features of
   the profile solid: protruding parts extruded from their shape-view profile (knobs round), raised
   repeated parts (keys) on a keyboard cut back to their floor, recesses cut. Built beside the mesh,
   behind `"construction": "parts"`; shown on the typewriter first, then all seven.
4. **Tessellate and texture from the part model (step 4)**, so the game mesh carries the parts.
5. **QA on the main body (step 1c)** and **fidelity profiles (step 2)**.
6. Detail views into the part graph (step 5); dryer/mixer round parts from the same rule.

Each step: before/after images, all seven objects plus the drawn set, nothing worse, R9 holds.
